# Daily-Weather-Rain-Alert
🌧️ Daily Weather Rain Alert (n8n Workflow)

This project is an automation workflow built with n8n that checks daily weather conditions and sends an email alert if rain is detected.

🚀 Features
🌍 Fetches real-time weather data using API
☁️ Detects rain conditions automatically
📧 Sends instant email alerts
⚡ Simple and lightweight automation
🔧 Workflow Overview
Trigger
Manual or scheduled execution
Weather API Call
Fetches live weather data
Condition Check
Detects if weather contains "Rain"
Email Notification
Sends alert to user
⚙️ Setup Guide
1. Import Workflow
Open n8n
Import JSON file
2. Add Credentials

You must configure:

Weather API Key
Gmail OAuth2
🔑 Required Configuration

Replace placeholders:

YOUR_API_KEY
YOUR_CITY
YOUR_EMAIL
🔒 Security Notice
Never upload real API keys to GitHub
Use environment variables
Keep credentials inside n8n credential manager
